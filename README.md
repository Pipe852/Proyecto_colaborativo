# README — Página de Pensamiento Computacional (Versión Estática)

## 1. Descripción general

Esta página es un recurso **estático** diseñado para explicar de manera clara y sencilla el concepto de **Pensamiento Computacional**, dividido en tres secciones temáticas que corresponden a tres personas o expositores. Cada sección contiene un tema central del pensamiento computacional, ejemplos y recursos para su comprensión.

La página fue desarrollada únicamente con **HTML y CSS**, sin utilizar bases de datos, lenguajes del lado del servidor ni funcionalidades dinámicas. Por lo tanto, su objetivo es **informativo** y funciona como una página de consulta o material de apoyo educativo.

## 3. ¿Qué es una página estática?

Una **página estática** es un sitio web en el cual el contenido es **fijo** y no cambia dinámicamente en función de la interacción del usuario o de datos externos. Su información se guarda directamente en archivos HTML, CSS y, en algunos casos, JavaScript para interactividad ligera.

### Características principales de una página estática:

* **Contenido fijo:** el usuario siempre ve la misma información, salvo que el archivo sea modificado manualmente por el creador.
* **Simplicidad:** no requiere servidores complejos, bases de datos ni lenguajes del lado del servidor (como PHP, Python o Node.js).
* **Rapidez:** al no depender de procesos dinámicos, la carga suele ser más rápida.
* **Seguridad:** al no manejar bases de datos ni formularios complejos, reduce riesgos de ataques.
* **Mantenimiento manual:** cualquier actualización requiere editar los archivos HTML/CSS directamente.

---

## 4. Objetivo educativo de la página

El propósito de este sitio estático es **documentar y difundir conceptos fundamentales del pensamiento computacional** de una manera sencilla, organizada y accesible para estudiantes y docentes. Sirve como:

* Material de apoyo en clases.
* Documento de referencia para exposiciones grupales.
* Recurso digital básico que no necesita conexión a bases de datos ni programación avanzada.

---

## 5. Limitaciones de la página

* No incluye interactividad avanzada (formularios, bases de datos, autenticación).
* No permite personalización dinámica del contenido.
* Requiere actualización manual del código para añadir o modificar información.

---

## 6. Cómo visualizar la página

1. Descargar el archivo **HTML** (y la carpeta de estilos si se separa el CSS).
2. Abrir el archivo en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
3. No se requiere instalación de servidores ni software adicional.

## 7. Posibles mejoras futuras

Si se desea evolucionar esta página estática hacia algo más completo, se pueden incluir:

* Interactividad básica con JavaScript.
